Why accept a worse move? +

A shorter tour is better. Hill climbing only accepts moves that don’t increase distance, so it can get stuck.

Annealing sometimes accepts a longer route with probability exp(−Δ / T). At high temperature, it explores more. As the temperature falls, it becomes less willing to go uphill.

Each move reverses a segment of the tour. We keep the best route separately, because the current route can get worse. The comparison uses the same starting tour and segment-index proposals.

Neither method guarantees the optimal route in this finite run. Try temperature 0, then 20 with the same seed.
