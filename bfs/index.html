Under the hood +

State versus node

A state is a graph label, such as B. A Node stores that state, its parent node, and its depth. Following parents backward reconstructs the path.

Expand and yield

expand(graph, node) generates neighboring nodes. Python’s yield supplies one child at a time and pauses the generator until the loop requests another. Generating a child does not mean that child has been expanded.

Queue and duplicate handling

A deque provides FIFO removal. A state is marked seen when enqueued, so cycles cannot add it repeatedly. Neighbors in these presets are alphabetical; that order resolves ties between equally short paths.

Guarantees and counting

For a finite graph, BFS finds a path if one exists and minimizes the number of edges. It minimizes cost only when every edge has the same cost. Here the goal is checked on removal, before expansion, and is excluded from the expanded count.

Algorithm versus playback

Standard graph BFS takes O(V + E) time and O(V) auxiliary space. This teaching version also copies the queue, parent map, and expanded list each step. Those snapshots can add O(V²) time and storage.
