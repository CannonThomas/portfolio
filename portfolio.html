to working code.

Built alongside an Intro to AI class, with algorithms implemented directly in Python.

The engineering decision

Keep the search engine independent of its interface. The same Python source powers a local desktop app and this browser demo, with no application server to maintain.

Correctness before comparisons

Tests cover weighted detours, unreachable goals, and 60 seeded maps checked against an independent path-cost oracle. Runtime measurements exclude animation.
