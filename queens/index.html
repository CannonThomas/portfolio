Under the hood +

A constraint-satisfaction problem

Each row is a variable; its queen’s column is the value. For rows i and j, require col[i] ≠ col[j] and |col[i] − col[j]| ≠ |i − j|. One queen per row is built into the representation.

The search

The Python solver tries rows from top to bottom and columns from left to right. Sets track occupied columns and diagonal identifiers row − col and row + col. Unsafe placements are rejected before recursion. Exhausting a row undoes the previous placement.

What the animation counts

A tested square is one candidate column examined, including rejected candidates. A backtrack is one placed queen removed after its branch fails. Playback records placements, rejections, removals, and the final outcome. A rejected square is only a preview, not an extra queen on the board.

Guarantees and cost

This complete search returns the first valid solution or establishes that none exists. It does not enumerate all solutions. Ignoring pruning, search work is bounded by O(N · N!) with O(N) working state; copying N columns per recorded event adds O(N) time and storage per event. The manual board’s conflict check is O(N²).

How this relates to annealing

Backtracking builds a valid partial board and undoes dead ends. An annealing version could instead keep N queens on the board and minimize the number of attacking pairs, sometimes accepting extra conflicts. This project implements backtracking; Route Lab implements annealing.
